# Aba Equip (helper 2.4.0) — plano de implementação

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Nova aba "Equip" no helper que ranqueia toda peça da conta (corpo dos 4 + depósito) por vocação e slot, mostra o atual contra o melhor com ganho e motivos, marca os atributos mortos de cada peça e lista o que é dispensável. Só recomenda.

**Architecture:** Tudo no userscript único `tibidle-helper.user.js`. Três camadas: (1) leitura — roster completo do `welcome`/`resume` (novo campo `ESTADO_WS.rosterFull`, com fallback pela fibra React) e depósito por `depot_get`→`depot_state`; (2) modelo puro entre marcadores `/* @@EQUIP-PURO-INICIO */ … /* @@EQUIP-PURO-FIM */` (`PESOS_EQUIP`, `pontuarPeca`, `candidatosEquip`, `distribuirEquip`) testável no node com as fixtures de 28/09; (3) tela `telaEquip()` com 4 sub-abas. Atributos base vêm de `GET /item/info?ids=` (cache em localStorage por nome). Desenho aprovado em `docs/plans/2026-09-28-equip-design.md`.

**Tech Stack:** JavaScript de navegador (Tampermonkey, `@run-at document-start`), WebSocket do jogo (grampo já existente), REST público do jogo, `localStorage` por conta (prefixo `LS`). Testes: node 24 lendo o trecho puro do userscript com `new Function`. Sem git no projeto: o "commit" de cada tarefa é salvar o arquivo e rodar `node --check`.

**Regras do projeto que valem aqui:**
- Editar o arquivo com a ferramenta Edit ou com heredoc Python entre aspas simples (`<<'EOF'`) — nunca heredoc bash sem aspas: o arquivo tem `$` e `$$` (memória `tibidle-editar-com-heredoc-python`). Blocos grandes: escrever num arquivo temporário e inserir com Python.

**Fatos do jogo que o código assume (confirmados ao vivo em 28/09):**
- `roster[i].equipment` = `{head, armor, legs, boots, shield, weapon, necklace, ring}` → `{id, iid, name, attrs, forja{fonte, refino, raridade, atributos[{id,valor}], potenciaBase}, value}`. Paladino não tem `shield` (arco de duas mãos).
- `attrs.slot` usa `feet` (botas) e `hand` (arma); o depósito usa `boots`/`weapon`. Normalizar para os nomes do roster.
- `depot_state.data.entries[]` = `{itemName, count, iid?, forja?, slot?}`; só entradas com `forja` e `slot` são equipamento purificado. `used/total` = lugares.
- `/item/info?ids=1,2,3` (sem login) → `[{id, name, attrs, imbuements, sell, buy, equipPreview?}]`. Id por nome: `/assets/v167/items-by-name.json` (`{nome: id}`, 221 KB).
- `attrs.vocation` = `"Knight;true, Elite Knight"` etc. Ausente = qualquer vocação. `attrs.slotType === 'two-handed'` ocupa arma+escudo. `attrs.weaponType`: `sword|axe|club|fist` (só Knight), `distance` (só Paladino), `wand` (vocation diz), `shield`, `spellbook`.
- Ids de forja (Wiki /forja): ofensivos `dano_fisico, dano_magico, dano_elem_{fogo,gelo,energia,terra,morte,sagrado}, roubo_vida_chance, roubo_vida_quantia, critico_chance, critico_dano, corpo_a_corpo, distancia, nivel_magico`; defensivos `resist_{fogo,gelo,energia,terra,morte,sagrado}, resist_fisica, protecao_magica, escudo, max_hp, max_mana, capacidade, regen_vida, regen_mana, cura_propria, chance_de_loot` (+ roubo_vida_* também cai em defensivos).

```js
    /* =========================================================================
     *  ⭐ v2.4.0 — EQUIP: leituras. Corpo dos 4 (welcome/resume → rosterFull;
     *  fallback: fibra React, o mesmo caminho de data/estado-party.json),
     *  depósito (depot_get → depot_state) e atributos base por /item/info.
     *  Só leitura — depot_get não muda nada no servidor.
     * ====================================================================== */
    function lerRosterFibra() {
        try {
            const raiz = tid('shell') || $('.s-ui-root'); if (!raiz) return null;
            const k = Object.keys(raiz).find(x => x.startsWith('__reactFiber$')); if (!k) return null;
            let f = raiz[k]; while (f && f.return) f = f.return;
            const vistos = new Set(); let shell = null;
            const olhar = o => { if (!o || typeof o !== 'object' || vistos.has(o)) return; vistos.add(o);
                if (!shell && o.roster && o.bag && 'equipSlots' in o) shell = o; };
            const pilha = [f]; let g = 0;
            while (pilha.length && g++ < 200000 && !shell) {
                const x = pilha.pop(); if (!x) continue;
                if (x.memoizedProps && typeof x.memoizedProps === 'object') { olhar(x.memoizedProps); for (const v of Object.values(x.memoizedProps)) olhar(v); }
                let h = x.memoizedState, g2 = 0;
                while (h && g2++ < 200) { olhar(h.memoizedState); if (h.memoizedState && typeof h.memoizedState === 'object') for (const v of Object.values(h.memoizedState)) olhar(v); h = h.next; }
                if (x.child) pilha.push(x.child); if (x.sibling) pilha.push(x.sibling);
            }
            return shell && Array.isArray(shell.roster) ? clonar(shell.roster) : null;
        } catch (e) { return null; }
    }
    function rosterEquip() {
        if (ESTADO_WS.rosterFull) return ESTADO_WS.rosterFull;
        const r = lerRosterFibra();
        if (r && r.some(x => x && x.equipment)) { ESTADO_WS.rosterFull = r; ESTADO_WS.rosterFull_t = Date.now(); }
        return ESTADO_WS.rosterFull;
    }
    async function lerDepot() {
        if (!socketAberto()) return { erro: 'socket do jogo não está aberto' };
        const antes = ESTADO_WS.depot_t;
        enviarWS({ type: 'depot_get', data: {} });
        const ok = await esperarQue(() => ESTADO_WS.depot_t > antes, 5000, 100);
        return ok ? { depot: ESTADO_WS.depot } : { erro: 'depot_state não chegou em 5 s' };
    }
    /* atributos base por nome. Cache em localStorage (equip_base) por 7 dias;
     * id por nome vem de /assets/v167/items-by-name.json (cache equip_ids). */
    let _idsPorNome = null;
    async function idsPorNome() {
        if (_idsPorNome) return _idsPorNome;
        const c = ler('equip_ids', null);
        if (c && c.t && Date.now() - c.t < 7 * 864e5 && c.m) { _idsPorNome = c.m; return c.m; }
        const m = await buscarJSON('/assets/v167/items-by-name.json');
        _idsPorNome = m; guardar('equip_ids', { t: Date.now(), m });
        return m;
    }
    async function basePorNome(nomes) {
        const cache = ler('equip_base', {});
        const ids = await idsPorNome();
        const faltam = [...new Set(nomes)].filter(n => !cache[n] && ids[n] != null);
        for (let i = 0; i < faltam.length; i += 100) {
            const lote = faltam.slice(i, i + 100);
            try {
                const lista = await buscarJSON('/item/info?ids=' + lote.map(n => ids[n]).join(','));
                for (const it of lista) cache[it.name] = { id: it.id, attrs: it.attrs || {}, sell: it.sell || 0, equipPreview: it.equipPreview || null };
            } catch (e) { log('equip: /item/info falhou: ' + e.message, 'erro'); }
        }
        if (faltam.length) guardar('equip_base', cache);
        return cache;
    }
```

```js
    const ROTULO = Object.assign({
        attack: 'attack', armor: 'armor', defense: 'defesa', extradef: 'defesa extra', magiclevelpoints: 'nível mágico (base)',
        skillsword: 'sword (base)', skillaxe: 'axe (base)', skillclub: 'club (base)', skilldist: 'distance (base)', skillshield: 'shield (base)',
        hitchance: 'acerto', absorbpercentphysical: 'resist física (base)', absorbpercentpoison: 'resist terra (base)',
        dano_fisico: 'dano físico', dano_magico: 'dano mágico', roubo_vida_chance: 'roubo de vida (chance)', roubo_vida_quantia: 'roubo de vida (quantia)',
        critico_chance: 'crítico (chance)', critico_dano: 'crítico (dano)', corpo_a_corpo: 'corpo a corpo', distancia: 'distância', nivel_magico: 'nível mágico',
        resist_fisica: 'resist física', protecao_magica: 'proteção mágica', escudo: 'escudo', max_hp: 'max HP', max_mana: 'max mana',
        capacidade: 'capacidade', regen_vida: 'regen vida', regen_mana: 'regen mana', cura_propria: 'cura própria', chance_de_loot: 'chance de loot'
    }, Object.fromEntries(ELEM.map(e => ['dano_elem_' + e, 'dano ' + e])), Object.fromEntries(ELEM.map(e => ['resist_' + e, 'resist ' + e])),
       Object.fromEntries(ELEM.map(e => ['absorbpercent' + ELEM_EN[e], 'resist ' + e + ' (base)'])));
    const rotulo = (id) => ROTULO[id] || id;
    const normalizarSlot = (s) => s === 'feet' ? 'boots' : s === 'hand' ? 'weapon' : s;
    const VOC_NOME = { KNIGHT: 'knight', PALADIN: 'paladin', SORCERER: 'sorcerer', DRUID: 'druid' };
    function vocacaoPode(attrs, voc) {
        const a = attrs || {};
        if (a.vocation) return String(a.vocation).toLowerCase().includes(VOC_NOME[voc]);
        const w = a.weaponType || a.weapontype;
        if (w === 'sword' || w === 'axe' || w === 'club' || w === 'fist') return voc === 'KNIGHT';
        if (w === 'distance') return voc === 'PALADIN';
        if (w === 'shield') return voc !== 'PALADIN';
        return true;
    }
    /* peça = {nome, slot, attrs (base), forja{raridade, atributos[]}, equipPreview?}
     * → {pontos, motivos[≤2], contam[], mortos[], temporario, detalhe[{id, valor, pt}]} */
    function pontuarPeca(peca, voc) {
        const P = PESOS_EQUIP[voc] || {};
        const a = peca.attrs || {};
        const detalhe = [];
        const add = (id, valor, pt) => detalhe.push({ id, valor, pt: Math.round(pt * 100) / 100 });
        let temporario = false;
        let baseAttrs = a;
        if (peca.equipPreview && peca.equipPreview.attrs) { temporario = true; baseAttrs = Object.assign({}, a, peca.equipPreview.attrs); }
        const fator = temporario ? 0.5 : 1;
        const IGNORAR = new Set(['weight', 'level', 'range', 'mana', 'fromDamage', 'toDamage', 'imbuementslot', 'duration', 'charges', 'speed',
                                 'transformequipto', 'transformdeequipto', 'decayTo', 'showduration', 'showAttributes', 'stopduration',
                                 'manaticks', 'healthticks', 'showCharges', 'containersize', 'augments', 'value']);
        for (const [k, v] of Object.entries(baseAttrs)) {
            if (typeof v !== 'number' || IGNORAR.has(k)) continue;
            if (k === 'managain') { add('regen_mana', v, v * 0.5 * (P.regen_mana || 0) * fator); continue; }
            if (k === 'healthgain') { add('regen_vida', v, v * 0.5 * (P.regen_vida || 0) * fator); continue; }
            if (k === 'skillmagic' || k === 'magiclevelpoints') { add('magiclevelpoints', v, v * (P.magiclevelpoints || 0) * fator); continue; }
            if (k.startsWith('skillboost') || k === 'life leech' || k === 'mana leech' || k === 'critical hit' || k === 'elemental damage' || k.startsWith('elemental protection') || k === 'paralysis deflection' || k === 'increase speed') continue; // encaixes de imbuement, não bônus
            if (k in P) { if (P[k]) add(k, v, v * P[k] * fator); else add(k, v, 0); continue; }
        }
        // wand/rod: dano fixo por tiro menos a mana que ele rouba da magia
        if ((a.weaponType === 'wand' || a.wandType) && a.fromDamage != null && voc !== 'KNIGHT' && voc !== 'PALADIN') {
            const medio = (Number(a.fromDamage) + Number(a.toDamage)) / 2;
            add('dano da wand', medio, medio * WAND_PT_DANO);
            if (a.mana) add('mana por tiro', a.mana, -Number(a.mana) * WAND_PT_MANA);
        }
        for (const f of ((peca.forja && peca.forja.atributos) || [])) {
            const p = P[f.id]; add(f.id, f.valor, (p || 0) * Number(f.valor));
        }
        const pontos = Math.round(detalhe.reduce((s, d) => s + d.pt, 0) * 10) / 10;
        const contam = detalhe.filter(d => d.pt > 0).sort((x, y) => y.pt - x.pt);
        const mortos = detalhe.filter(d => d.pt === 0).map(d => d.id);
        const motivos = contam.slice(0, 2).map(d => `${rotulo(d.id)} +${d.valor} (${d.pt} pt)`);
        return { pontos, motivos, contam: contam.map(d => d.id), mortos, temporario, detalhe };
    }
    /* roster (welcome/fibra) + depot_state.entries + base{nome:{attrs,sell,equipPreview}} → peças
     * {iid, nome, slot, attrs, forja, equipPreview, sell, origem:'corpo'|'depósito', dono?:voc, duasMaos} */
    function candidatosEquip(roster, depot, base) {
        const out = [];
        const b = (nome) => base[nome] || { attrs: {}, sell: 0, equipPreview: null };
        for (const r of (roster || [])) for (const [slot, it] of Object.entries(r.equipment || {})) {
            if (!it || !it.name) continue;
            const k = b(it.name);
            const attrs = Object.assign({}, k.attrs, it.attrs || {});
            out.push({ iid: it.iid || (r.vocation + ':' + slot), nome: it.name, slot: normalizarSlot(slot), attrs, forja: it.forja || { raridade: 0, atributos: [] },
                       equipPreview: k.equipPreview, sell: k.sell || it.value || 0, origem: 'corpo', dono: r.vocation, duasMaos: attrs.slotType === 'two-handed' });
        }
        for (const e of ((depot && depot.entries) || [])) {
            if (!e.forja || !e.slot) continue;
            const k = b(e.itemName);
            out.push({ iid: e.iid, nome: e.itemName, slot: normalizarSlot(e.slot), attrs: k.attrs, forja: e.forja, equipPreview: k.equipPreview,
                       sell: k.sell || 0, origem: 'depósito', dono: null, duasMaos: k.attrs.slotType === 'two-handed' });
        }
        return out;
    }
    /* Distribuição gulosa: cada peça vai para UM personagem. Ganho = pontos − pontos do
     * atual no slot. Arma de duas mãos compete com (melhor 1 mão + melhor escudo).
     * → {porVoc:{VOC:{slot:{atual, atualPt, melhor, melhorPt, ganho, candidatos[]}}}, reservas:Set(iid), dispensaveis:[peça+motivo], usadas:Set} */
    function distribuirEquip(pecas, vocs) {
        vocs = vocs || Object.keys(PESOS_EQUIP);
        const pont = new Map();   // iid|voc → resultado
        const P = (p, v) => { const k = p.iid + '|' + v; if (!pont.has(k)) pont.set(k, pontuarPeca(p, v)); return pont.get(k); };
        const porVoc = {};
        for (const v of vocs) {
            porVoc[v] = {};
            for (const s of SLOTS_EQUIP) {
                if (v === 'PALADIN' && s === 'shield') continue;
                const atual = pecas.find(p => p.origem === 'corpo' && p.dono === v && p.slot === s) || null;
                const cands = pecas.filter(p => p.slot === s && vocacaoPode(p.attrs, v)).map(p => ({ peca: p, r: P(p, v) })).sort((x, y) => y.r.pontos - x.r.pontos);
                porVoc[v][s] = { atual, atualPt: atual ? P(atual, v).pontos : 0, melhor: null, melhorPt: 0, ganho: 0, candidatos: cands };
            }
        }
        // ganhos de todos os (peça, voc, slot), maior primeiro; empate → Knight
        const ordemVoc = ['KNIGHT', 'SORCERER', 'DRUID', 'PALADIN'];
        const fila = [];
        for (const v of vocs) for (const s of Object.keys(porVoc[v])) for (const c of porVoc[v][s].candidatos) {
            fila.push({ v, s, peca: c.peca, pt: c.r.pontos, ganho: c.r.pontos - porVoc[v][s].atualPt });
        }
        fila.sort((x, y) => (y.ganho - x.ganho) || (ordemVoc.indexOf(x.v) - ordemVoc.indexOf(y.v)));
        const usadas = new Set(), cheios = new Set();
        for (const f of fila) {
            const chave = f.v + '|' + f.s;
            if (usadas.has(f.peca.iid) || cheios.has(chave)) continue;
            if (f.peca.duasMaos && f.s === 'weapon' && f.v !== 'PALADIN') {
                // só vale se bater a melhor arma de 1 mão + o melhor escudo livres
                const arma1 = porVoc[f.v].weapon.candidatos.find(c => !c.peca.duasMaos && !usadas.has(c.peca.iid));
                const esc = porVoc[f.v].shield ? porVoc[f.v].shield.candidatos.find(c => !usadas.has(c.peca.iid)) : null;
                if ((arma1 ? arma1.r.pontos : 0) + (esc ? esc.r.pontos : 0) >= f.pt) continue;
                if (porVoc[f.v].shield) { cheios.add(f.v + '|shield'); porVoc[f.v].shield.melhor = null; porVoc[f.v].shield.ganho = -porVoc[f.v].shield.atualPt; }
            }
            if (f.s === 'shield' && porVoc[f.v].weapon.melhor && porVoc[f.v].weapon.melhor.duasMaos) continue;
            usadas.add(f.peca.iid); cheios.add(chave);
            porVoc[f.v][f.s].melhor = f.peca; porVoc[f.v][f.s].melhorPt = f.pt; porVoc[f.v][f.s].ganho = Math.round(f.ganho * 10) / 10;
        }
        // reservas: segunda melhor de cada (voc, slot) que não foi usada
        const reservas = new Set();
        for (const v of vocs) for (const s of Object.keys(porVoc[v])) {
            const r = porVoc[v][s].candidatos.find(c => !usadas.has(c.peca.iid));
            if (r) reservas.add(r.peca.iid);
        }
        const dispensaveis = pecas.filter(p => !usadas.has(p.iid) && !reservas.has(p.iid)).map(p => {
            let melhorUso = null;
            for (const v of vocs) if (vocacaoPode(p.attrs, v) && porVoc[v][p.slot]) {
                const top = porVoc[v][p.slot].melhor; if (!top) continue;
                const d = P(top, v).pontos - P(p, v).pontos;
                if (!melhorUso || d < melhorUso.d) melhorUso = { v, top, d };
            }
            return Object.assign({}, p, { motivo: melhorUso ? `superada por ${melhorUso.top.nome} (${melhorUso.v.toLowerCase()}, −${Math.round(melhorUso.d * 10) / 10} pt)` : 'nenhuma vocação usa' });
        }).sort((a, b) => (b.sell || 0) - (a.sell || 0));
        return { porVoc, reservas, dispensaveis, usadas };
    }
    /* @@EQUIP-PURO-FIM */
```
