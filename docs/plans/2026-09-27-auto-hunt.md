# Auto Hunt + Status (helper 1.9.0) — plano de implementação

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Quando a mochila chega no limite, o helper encerra a caçada, purifica os selados, vende no NPC, guarda o resto no depot e volta para a hunt memorizada; a aba Estado vira Status com Venda rápida e Finalizar hunt.

**Architecture:** Tudo dentro do userscript de arquivo único `tibidle-helper.user.js`. Cinco funções de passo (`finalizarHunt`, `purificarTodos`, `venderNoNpc`, `guardarNoDepot`, `voltarParaHunt`) + orquestrador sequencial `cicloDeVenda()` com flag de reentrada. O amostrador de 3 s (`amostrar`) só avalia o gatilho. Falha em qualquer passo desliga a automação. Desenho aprovado em `docs/plans/2026-09-27-auto-hunt-design.md`.

**Tech Stack:** JavaScript de navegador (Tampermonkey, `@run-at document-start`), âncoras `data-testid` do jogo, `localStorage` por conta (prefixo `LS`). Sem framework de teste: verificação é ida-e-volta no navegador do Playwright via `window.__tbHelper`. Sem git no projeto (não há commits; o "commit" de cada tarefa é salvar o arquivo e rodar a checagem de sintaxe).

**Regras do projeto que valem aqui:**
- Editar o arquivo com a ferramenta Edit ou com heredoc Python entre aspas simples — nunca `sed`/heredoc bash sem aspas: o arquivo tem `$` e `$$` e um cifrão comido já derrubou o boot inteiro (memória `tibidle-editar-com-heredoc-python`).
- Nada escreve no jogo sem botão ou sem a chave "Ativar automação" ligada pelo dono (memória `tibidle-nada-automatico-nos-slots`).
- Depois de salvar, o Tampermonkey do perfil do Playwright atualiza sozinho a partir do arquivo; F5 na aba do jogo carrega a versão nova (o jogo pode cair no lobby "SEU GRUPO" → clicar ENTRAR NO JOGO).

**Checagem de sintaxe (usada em todas as tarefas):**
```
node --check tibidle-helper.user.js
```
Esperado: sem saída, exit 0. Se `node` não existir, abrir a aba do jogo com F5 e conferir no console que não há `SyntaxError` e que o painel mostra `v1.9.0`.

```js
    let _cicloEmCurso = false, _ultimoCiclo = 0;
    const CICLO_INTERVALO_MIN_MS = 5 * 60 * 1000;

    /* origem: 'auto' (gatilho da mochila), 'venda' (botão Venda rápida: passos
     * 2-4, exige cidade) ou 'finalizar' (botão Finalizar hunt: só o passo 1). */
    async function cicloDeVenda(origem) {
        if (_cicloEmCurso) { log('ciclo já em andamento', 'erro'); return false; }
        if (_aprendendo) { log('medindo dano — ciclo adiado', 'erro'); return false; }
        _cicloEmCurso = true;
        const a = autoHunt();
        const desligar = (passo, erro) => {
            log(`AUTO HUNT parou no passo "${passo}": ${erro}` + (a.on ? ' — automação DESLIGADA' : ''), 'erro');
            if (a.on) guardarAutoHunt({ on: false });
        };
        try {
            log(`ciclo de venda (${origem}) iniciado — mochila ${(capLivre() || {}).pct}% livre`, 'info');
            if (origem !== 'venda') {
                const r1 = await finalizarHunt();
                if (r1.erro) { desligar('finalizar', r1.erro); return false; }
                if (origem === 'finalizar') return true;
            } else if (emHunt()) { log('Venda rápida só na cidade — use Finalizar hunt antes', 'erro'); return false; }
            const r2 = await purificarTodos();
            if (r2.pulou) log('purificar: ' + r2.pulou + ' (pulei)', 'info');
            const r3 = await venderNoNpc();
            if (r3.erro) { desligar('vender', r3.erro); return false; }
            const r4 = await guardarNoDepot();
            if (r4.erro) { desligar('depot', r4.erro); return false; }
            if (origem === 'auto' && a.voltar) {
                if (a.huntId == null) { desligar('voltar', 'nenhuma hunt memorizada'); return false; }
                const r5 = await voltarParaHunt(a.huntId);
                if (r5.erro) { desligar('voltar', r5.erro); return false; }
            }
            log('ciclo de venda terminado', 'ok');
            return true;
        } catch (e) {
            desligar('inesperado', e.message);
            return false;
        } finally {
            _cicloEmCurso = false; _ultimoCiclo = Date.now();
            renderizar();
        }
    }

    function gatilhoAutoHunt() {
        const a = autoHunt();
        if (!a.on || a.huntId == null || _cicloEmCurso || _aprendendo) return;
        if (!emHunt() || modalAberto()) return;
        if (Date.now() - _ultimoCiclo < CICLO_INTERVALO_MIN_MS) return;
        if (!mochilaNoLimite()) return;
        cicloDeVenda('auto');
    }
```
